# demo-dao-jdbc

# 📦 Projeto JDBC com Padrão DAO

Este projeto é uma implementação prática do padrão **DAO (Data Access Object)** utilizando **JDBC** em Java, com foco em boas práticas de acesso a dados, organização de código e separação de responsabilidades.

---

## 🚀 Objetivo

Demonstrar como estruturar uma aplicação Java que se comunica com banco de dados relacional utilizando:

- JDBC puro  
- Padrão DAO  
- Separação em camadas  
- Tratamento de exceções  
- Reuso de conexões  

---

## 🧠 Conceitos Aplicados

- **DAO (Data Access Object)** → abstração da camada de acesso a dados  
- **Entities (DTOs)** → representação dos dados no sistema  
- **Factory Pattern** → criação de DAOs  
- **Connection Factory** → gerenciamento de conexões com o banco  
- **CRUD completo com SQL**:
  - Insert  
  - Update  
  - Delete  
  - Select
